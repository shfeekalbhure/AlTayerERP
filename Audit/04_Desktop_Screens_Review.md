# مراجعة شاشات Desktop

هذه مراجعة ثابتة؛ لم تُشغل WinForms، ولذلك «تفتح/تحفظ/تطبع» غير قابل للتحقق تشغيليًا.

## الموجود في شجرة النظام

المجموعات، الشركات، الفروع، الدول، المحافظات، المدن، المستخدمون، الأدوار، الصلاحيات، السنوات والفترات، الإعدادات، العملات، دليل الحسابات، مراكز التكلفة، الصناديق، البنوك، الأطراف، طلب الصرف، سندات قبض/صرف/قيد، المرفقات، التدقيق، الجلسات، ميزان المراجعة والأستاذ العام.

## الحالة

| التصنيف | النتيجة |
|---|---|
| منفذ لكنه غير مختبر | غالبية الشاشات والأحداث والتحميل عبر API |
| منفذ جزئيًا | سند الصرف يرث `FrmReceiptVoucher`، مع نصوص ثابتة ما زالت تقول «سند القبض» داخل مسار المرفقات |
| غير قابل للتحقق | إعادة الحقول عند نقر الجدول، التصميم على الدقات المتوسطة، الطباعة الفعلية، منع فتح نافذتين |

## دليل

`FrmMain.cs:380-417` يسجل 38 وجهة تقريبًا. `FrmPaymentVoucher.cs:8-13` يثبت النوع PAYMENT، لكن `Accounting/ReceiptVoucher/FrmReceiptVoucher.Actions.cs:102-108` يعلن «احفظ أو ابحث عن سند القبض» دون تمييز النوع.

العيوب: AT-004، AT-011، AT-012.
