# سجل الميزات الناقصة

| المجال | الحالة | ملاحظة |
|---|---|---|
| Driver App | مطلوب وظيفيًا وغير موجود كمشروع قابل للمراجعة | ليس نقص شاشة Desktop |
| Customer App | مطلوب وظيفيًا وغير موجود كمشروع قابل للمراجعة | ليس نقص شاشة Mobile.Office |
| البوليصة وأصنافها | غير موجود | لا Entity/API/UI تشغيلي مكتمل |
| مخازن/توريد/ترحيل/تسليم | غير موجود | لا تنفيذ قابل للمراجعة |
| رحلات/مركبات/سائق | غير موجود | لا تنفيذ قابل للمراجعة |
| GPS والوقود | غير موجود | لا صلاحيات جهاز أو خدمات موقع |
| Offline/mزامنة | غير موجود | لا SQLite أو sync queue |
| جمارك/مطالبات/مرتجعات | غير موجود | لا نموذج تشغيل |
| تذاكر نقل بري/محلي/دولي | مخطط فقط | لا وحدة مكتملة |
| Test automation | غير موجود | Markdown لا يكفي |
| نشر/rollback/versioning | غير موجود/غير قابل للتحقق | workflow بناء فقط |
