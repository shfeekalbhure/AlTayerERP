# مراجعة Mobile.Office

## منفذ

تسجيل الدخول، اختيار الشركة/الفرع/السنة، طلبات الصرف، سندات القبض والصرف والقيود، البحث، المرفقات، PDF لسندات القبض/الصرف، ميزان المراجعة والأستاذ العام.

## غير منفذ أو غير قابل للتحقق

| الحالة | البند |
|---|---|
| غير موجود | Offline database، queue للمزامنة، retry policy، cache مرجعي |
| غير موجود | كاميرا/GPS وصلاحياتهما لتطبيق المكتب |
| غير قابل للتحقق | adb reverse على جهاز فعلي، PDF المحفوظ وفتحه، 401/403/409 على Android |
| منفذ جزئيًا | التخزين الآمن للجلسة موجود، لكن BaseAddress ثابت للتطوير |

## عيب مانع للنشر

`MauiProgram.cs:22-27` يثبت `http://127.0.0.1:5021/`، وAndroidManifest يعلن `usesCleartextTraffic=true`. هذا يعمل مع adb reverse فقط ولا يصلح لشبكة فعلية أو إنتاج آمن.

العيوب: AT-003، AT-005، AT-010.
