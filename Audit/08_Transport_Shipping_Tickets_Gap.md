# فجوة النقل والشحن والتذاكر

## النتيجة

المتطلبات موثقة وظيفيًا، لكن لا توجد وحدات ERP قابلة للتدقيق للبوليصة والشحن والتشغيل. نتائج البحث الثابتة لا تظهر Entities/Controllers/Pages مكتملة للشحنة أو المستودع أو الرحلة أو السائق أو المركبة أو GPS.

| المجال | الحالة |
|---|---|
| البوليصة وأصنافها | غير موجود كموديل تشغيلي قابل للمراجعة |
| المستودع/التوريد/الترحيل/التسليم | غير موجود |
| الرحلات/السائقون/المركبات | غير موجود |
| دفاتر البوالص والجمارك والمطالبات | غير موجود |
| التذاكر المحلية/الدولية والنقل البري | غير موجود كموديل مكتمل |
| GPS والعمل دون اتصال للسائق | غير موجود |
| تطبيق Driver | مطلوب وظيفيًا وغير موجود كمشروع قابل للمراجعة |
| تطبيق Customer | مطلوب وظيفيًا وغير موجود كمشروع قابل للمراجعة |

هذا سجل فجوة نطاق وليس عيبًا في شاشة واحدة. العيوب: AT-014 وAT-015.
