# اختبار قبول: رسائل أخطاء API في تطبيق الجوال — P0-1

قاعدة الاختبار الوحيدة: `altayer_erp_db_clean`.

| رقم الاختبار | الحالة والخطوات | النتيجة المتوقعة | الحالة |
|---|---|---|---|
| MOB-ERR-01 | أوقف API أو أزل `adb reverse` ثم حمّل الشركات أو قائمة طلبات الصرف. | تظهر فقط: «تعذر الاتصال بخدمة النظام. تأكد من تشغيل الخادم واتصال الجهاز.» ولا يظهر عنوان داخلي أو HTTP أو JSON. |  |
| MOB-ERR-02 | استخدم Token منتهيًا ثم نفّذ عملية محمية. | تظهر رسالة انتهاء الجلسة العربية، تمسح الجلسة، ويعود التطبيق إلى تسجيل الدخول دون عرض Token أو اسم قاعدة بيانات. |  |
| MOB-ERR-03 | سجّل بمستخدم بلا صلاحية ثم نفّذ عملية محمية. | تظهر فقط: «ليس لديك صلاحية لتنفيذ هذه العملية.» ويبقى المستخدم في الشاشة نفسها. |  |
| MOB-ERR-04 | افتح السجل من جهازين، عدّل السجل في الأول ثم احفظ من الثاني لإنتاج 409. | تظهر رسالة التعارض العربية بلا نص HTTP؛ وتعيد شاشة التفاصيل تحميل أحدث البيانات عند الإمكان. |  |
| MOB-ERR-05 | امنع تحميل الشركات أو اجعل استجابة الخدمة 500/غير صالحة. | تظهر رسالة خدمة النظام العربية فقط. |  |
| MOB-ERR-06 | افشل حفظ طلب صرف (403 أو 409 أو 500). | تظهر الرسالة العربية المطابقة للحالة، بلا HTTP raw text. |  |
| MOB-ERR-07 | افشل تحميل أو حفظ سند قبض. | تظهر الرسالة العربية المطابقة للحالة، بلا JSON أو Stack Trace. |  |
| MOB-ERR-08 | افشل تحميل أو حفظ سند صرف. | تظهر الرسالة العربية المطابقة للحالة، بلا JSON أو Stack Trace. |  |
| MOB-ERR-09 | افشل رفع أو حذف مرفق لطلب صرف أو سند. | تظهر الرسالة العربية المطابقة للحالة، بلا Connection String أو Token أو نص خادم خام. |  |

## دليل التنفيذ

- صورة لكل حالة تبين الرسالة العربية فقط.
- سجل Development (عند الحاجة) يقتصر على BaseAddress وEndpoint وStatusCode ونوع خطأ الاتصال وحالة وصول الطلب للخادم، ولا يحتوي Token أو Password أو Connection String.
