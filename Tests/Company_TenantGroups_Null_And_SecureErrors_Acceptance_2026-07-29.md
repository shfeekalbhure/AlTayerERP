# اختبار قبول شاشة الشركات والمجموعات التجارية

**الفرع:** `agent/unified-phase1-screens`  
**قيد الدمج:** ممنوع الدمج إلى `master` دون موافقة مالك المشروع.  
**قاعدة البيانات:** لا تغيير بنيوي ولا تعديل بيانات ضمن هذا الإصلاح.

## 1. سبب العطل

الحقل الاختياري `Group_Name_EN` كان معرفاً في كيان `TenantGroup` كـ`string` إجباري، بينما توجد سجلات قديمة بقيمة `NULL`. أدى ذلك إلى `InvalidCastException` أثناء تنفيذ `GetGroups()`.

## 2. اختبارات الحقول الاختيارية

### TG-NULL-01 — اسم إنجليزي NULL

- جهّز سجل مجموعة تجارية موجوداً مسبقاً تكون قيمة `Group_Name_EN` فيه `NULL`.
- افتح شاشة الشركات.

**النتيجة المتوقعة:**
- ينجح طلب `GET /api/TenantGroups`.
- تظهر المجموعة في المنسدلة.
- يعاد الاسم الإنجليزي كقيمة فارغة دون استثناء.

**دليل القبول:** صورة من منسدلة المجموعة التجارية وعدم ظهور رسالة خطأ.

### TG-NULL-02 — ملاحظات NULL

- استخدم مجموعة تكون `Notes` فيها `NULL`.
- افتح شاشة المجموعات التجارية أو نفذ طلب القائمة.

**النتيجة المتوقعة:** تحميل السجل دون `InvalidCastException` وإرجاع الملاحظات كقيمة فارغة في نتيجة القائمة.

**دليل القبول:** استجابة ناجحة أو صورة للشاشة.

### TG-REQ-01 — الحقول الإجبارية

- حاول حفظ مجموعة دون `Group_Code` أو `Group_Name_AR`.

**النتيجة المتوقعة:** رفض الحفظ برسالة عربية واضحة. لا تتحول الحقول الإجبارية إلى اختيارية.

## 3. اختبارات أمان الأخطاء

### SEC-ERR-01 — رسالة المستخدم

- تسبب بخطأ API اختباري في بيئة التطوير.
- افتح شاشة الشركات وحاول تحميل المجموعات.

**النتيجة المتوقعة:** تظهر رسالة عربية مختصرة فقط، دون Stack Trace أو مسارات ملفات أو رؤوس طلبات.

### SEC-ERR-02 — السجل المحلي

- راجع `%LocalAppData%/AlTayerERP/Logs/desktop-errors.log` بعد خطأ اختباري.

**النتيجة المتوقعة:** تفاصيل فنية منقحة، ولا تظهر أي قيمة بعد:
- `Authorization`
- `X-Session-Token`
- `Cookie` أو `Set-Cookie`
- `Password` أو `Pwd`
- `ConnectionString` أو `DefaultConnection`
- `Bearer`

### SEC-ERR-03 — Log الخادم

- راجع Log الخادم بعد فشل `GetGroups`.

**النتيجة المتوقعة:** يسجل الاستثناء الفني دون تسجيل رؤوس الطلبات أو محتوى المصادقة، ويرجع للعميل رسالة عربية عامة.

## 4. اختبار شاشة الشركات

1. فتح الشاشة وظهور منسدلة المجموعات النشطة.
2. إنشاء شركة وربطها بمجموعة.
3. تعديل الشركة.
4. النقر على الجدول واسترجاع الحقول والشعار.
5. البحث بالاسم أو البادئة.
6. إيقاف الشركة بسبب إلزامي.
7. إعادة التفعيل بسبب إلزامي.
8. رفع شعار وحذفه من المعاينة.
9. ظهور بيانات الإنشاء والتعديل والعدادات.
10. ترتيب الأزرار من أقصى اليمين.
11. عدم وجود أشرطة تمرير غير ضرورية.
12. وضوح الجدول والأعمدة والخط ودعم RTL.

## 5. معيار الإغلاق

لا تعتبر المشكلة مغلقة قبل:
- نجاح Build API وDesktop وMobile Android.
- نجاح تحميل منسدلة المجموعات مع وجود `NULL` في الحقول الاختيارية.
- عدم ظهور أو تسجيل أي Tokens أو Cookies أو كلمات مرور أو Connection Strings.
- عدم تعديل بنية قاعدة البيانات.
- عدم الدمج إلى `master`.
