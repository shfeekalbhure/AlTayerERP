# اختبار قبول حزمة الشركات والمجموعات التجارية وشجرة النظام

**الفرع:** `agent/unified-phase1-screens`  
**قيد قاعدة البيانات:** لا SQL ولا تعديل بنية أو بيانات.  
**قيد الدمج:** ممنوع الدمج إلى `master` قبل اعتماد مالك المشروع.

## 1. منع تعدد النسخ

### NAV-01 — فتح المجموعات التجارية مرة واحدة
- انقر نقرة مزدوجة على «المجموعات التجارية».
- كرر النقر خمس مرات بسرعة.
- **المتوقع:** تبويب واحد فقط داخل مساحة العمل، ولا تظهر نافذة مستقلة.
- **الدليل:** صورة لمساحة العمل وقائمة التبويبات.

### NAV-02 — فتح الشركات مرة واحدة
- افتح «الشركات» وكرر النقر والنقر المزدوج.
- **المتوقع:** تنشيط التبويب الموجود دون إنشاء Form جديد.
- **الدليل:** صورة تبويب الشركات الوحيد.

## 2. شجرة النظام

### TREE-01 — عدم تكرار Screen_Code
- وسّع جميع الأقسام.
- **المتوقع:** «المجموعات التجارية» و«الشركات» وكل شاشة تظهر مرة واحدة فقط.
- **الدليل:** صورة كاملة للشجرة.

### TREE-02 — الترتيب المعتمد
- تحقق من الأقسام بالترتيب: الهيكل المؤسسي، المستخدمون والصلاحيات، الأمن والرقابة، التقارير المالية، التهيئة والإعدادات.
- **المتوقع:** السنوات المالية ضمن التهيئة والإعدادات، لا ضمن الهيكل المؤسسي.
- **الدليل:** صورة الشجرة الموسعة.

### TREE-03 — العرض والتلميحات
- مرر المؤشر فوق اسم طويل.
- **المتوقع:** لا قص مؤثر؛ يظهر ToolTip، ولا يظهر تمرير أفقي غير لازم.
- **الدليل:** صورة للاسم والتلميح.

## 3. Endpoint المجموعات التجارية

### API-01 — قراءة NULL بأمان
- من Swagger نفذ `GET /api/TenantGroups` على قاعدة تحتوي `Group_Name_EN = NULL` أو `Notes = NULL`.
- **المتوقع:** HTTP 200، والقيم الاختيارية ترجع نصًا فارغًا، ولا يحدث `InvalidCastException`.
- **الدليل:** صورة استجابة Swagger دون أسرار.

### API-02 — قراءة سجل مفرد
- نفذ `GET /api/TenantGroups/{id}` للسجل نفسه.
- **المتوقع:** HTTP 200 دون `DBNull`.
- **الدليل:** صورة الاستجابة.

### API-03 — أمان الخطأ
- أوقف API مؤقتًا أو استخدم مسار اختبار يفشل.
- **المتوقع:** رسالة عربية مختصرة فقط.
- **يمنع ظهور:** JSON، Stack Trace، SQL، Authorization، X-Session-Token، Cookies، Passwords، Bearer Tokens، Connection Strings، ومسارات الجهاز.
- **الدليل:** صورة الرسالة وفحص Log منقح.

## 4. شاشة المجموعات التجارية

### TG-01 — تحميل البيانات والحالة الفارغة
- افتح الشاشة مع بيانات، ثم اختبر قاعدة/مرشح لا يرجع نتائج.
- **المتوقع:** يظهر الجدول عند وجود بيانات، ورسالة «لا توجد بيانات للمجموعات التجارية» عند الخلو.
- **الدليل:** صورتان.

### TG-02 — الأزرار
- تحقق من: جديد، حفظ، تعديل، إيقاف، إعادة تفعيل، طباعة، بحث، تحديث، إغلاق.
- **المتوقع:** نص عربي كامل دون رموز غامضة أو أسهم تمرير.
- **الدليل:** صورة شريط الإجراءات.

### TG-03 — الوظائف
- نفذ إضافة، نقر صف، تعديل، بحث، إيقاف بسبب، إعادة تفعيل بسبب، وطباعة.
- **المتوقع:** كل عملية تنجح وتظهر بيانات التدقيق والعدادات دون قص.
- **الدليل:** صور ورسائل النجاح والعدادات.

## 5. شاشة الشركات

### CO-01 — تحميل المنسدلة
- افتح الشركات.
- **المتوقع:** تحميل المجموعات النشطة، ويظهر الاسم العربي للسجل ذي الاسم الإنجليزي NULL.
- **الدليل:** صورة المنسدلة مفتوحة.

### CO-02 — الحفظ والتعديل والنقر
- احفظ شركة، اخترها من الجدول، عدّلها.
- **المتوقع:** استرجاع المجموعة وجميع الحقول والشعار والحالة.
- **الدليل:** صور قبل وبعد.

### CO-03 — البحث والحالة والشعار
- اختبر البحث، الإيقاف، إعادة التفعيل، رفع الشعار وحذفه.
- **المتوقع:** تعمل دون فتح نسخة ثانية ودون رسائل تقنية.
- **الدليل:** صور ورسائل الإجراءات.

### CO-04 — التصميم
- اختبر الحجم الكامل والمتوسط.
- **المتوقع:** RTL صحيح، الأزرار من أقصى اليمين، الجدول واضح ومرتفع، الأعمدة موزعة، الشعار بلا تمرير، بطاقات التدقيق غير مقصوصة، ولا تمرير أفقي غير لازم.
- **الدليل:** صورتان بالحجمين.
