# Main Shell — اختبارات القبول المحلية

تنفذ هذه القائمة على فرع `agent/unified-phase1-screens` فقط، ولا يدمج أي تغيير إلى `main` قبل نجاحها.

## 1. البناء والتشغيل

1. نفذ ملف `Database/2026-07-24_add_login_security.sql` مرة واحدة على `altayer_erp_db`.
2. في Visual Studio: **Restore NuGet Packages**.
3. نفذ **Clean Solution** ثم **Rebuild Solution**.
4. شغّل `AlTayerERP.API` ثم `AlTayerERP.Desktop`.

النتيجة المتوقعة: لا توجد أخطاء Compile، وتظهر شاشة الدخول ثم `FrmMain` فقط بعد دخول صحيح.

## 2. سياق الجلسة وشريط الحالة

- سجّل الدخول بشركة وفرع وسنة فعالة.
- تحقق من ظهور اسم الشركة، الفرع، السنة، والمستخدم في الشريط العلوي.
- تحقق من: `API: متصل` و`قاعدة البيانات: متصلة`.
- أوقف API مؤقتاً وانتظر 30 ثانية.

النتيجة المتوقعة: يتحول شريط الحالة إلى غير متصل، وتبقى واجهة المستخدم قابلة للعمل ضمن ما هو مفتوح.

## 3. قائمة الصلاحيات

- ادخل بمستخدم غير مدير نظام لديه `Can_View` لشاشة واحدة فقط.
- تحقق أن القائمة تعرض هذه الشاشة فقط ولا تعرض الأزرار السريعة غير المصرح بها.
- حاول فتح مسار غير مسموح عبر استدعاء API أو من أي زر ظاهر سابقاً.

النتيجة المتوقعة: الشاشة مخفية من القائمة، وAPI يرفض العملية حسب الصلاحية الخادمية.

- ادخل بمدير نظام `Is_System_Admin = true`.

النتيجة المتوقعة: تظهر الشاشات المتاحة في حزمة المرحلة الأولى حتى يكتمل كتالوج الصلاحيات التفصيلي.

## 4. مساحة العمل ومنع التكرار

- افتح `دليل الحسابات` مرتين من القائمة أو الإجراءات السريعة.
- افتح `سند القبض` مرتين.
- افتح شاشة ثانية ثم عد إلى `الرئيسية`.

النتيجة المتوقعة:
- لكل `Screen_Code` تبويب واحد فقط؛ الاستدعاء الثاني ينشّط التبويب المفتوح.
- لا تظهر نافذة `ShowDialog` منفصلة للشاشات التي فتحت من الغلاف.
- تبويب الرئيسية ثابت، وبقية التبويبات تغلق من القائمة السياقية.

## 5. التعديلات غير المحفوظة

- عند تطبيق `IWorkspaceDirtyAware` على شاشة تحرير، عدّل بيانات ثم اطلب إغلاق تبويبها.
- اختر إلغاء الإغلاق.

النتيجة المتوقعة: يبقى التبويب مفتوحاً. عند السماح بالإغلاق يغلق التبويب فقط.

## 6. الخروج الآمن

- اضغط `تسجيل الخروج` ثم أكد.
- أعد استخدام Access Token السابق على `GET /api/Auth/CurrentSession`.
- اختبر إغلاق `FrmMain` من زر X.

النتيجة المتوقعة:
- يغلق التبويب بعد معالجة التعديلات غير المحفوظة.
- تمسح `CurrentSession` والترويسات المحلية.
- يرد API بـ 401 للرمز الملغى عند توفر الاتصال.
- زر X يتبع نفس مسار الخروج ولا يترك رموزاً داخل تطبيق سطح المكتب.
