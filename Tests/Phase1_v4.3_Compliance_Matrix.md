## ضوابط لا تقبل الاستثناء
- Desktop عبر API فقط، والـBackend مصدر الحقيقة للترقيم والصلاحيات والاعتماد والترحيل.
- لا قيم شركة/فرع/سنة ثابتة؛ المصدر جلسة خادم أو مستند موثوق.
- لا دمج إلى `main` أو `master` قبل اجتياز القبول.
- قاعدة البيانات المصرح بها للتشغيل هي `altayer_erp_db`؛ أي ترقية آمنة ومراجعة فقط، بلا حذف أو إعادة إنشاء.
