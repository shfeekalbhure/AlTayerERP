# اختبارات قبول — Fail-Closed والتقارير المالية

## FrmMain عند تعطل API الصلاحيات

1. شغّل Desktop بجلسة صالحة ثم أوقف API أو اجعل `GET /api/SystemScreens` يرجع 500/401.
2. النتيجة المطلوبة: تظهر رسالة «الصلاحيات غير متاحة من الخادم»، تكون شجرة النظام فارغة، ولا تفتح بطاقات أو إجراءات سريعة أي شاشة.
3. كرر الاختبار بحساب مدير نظام.
4. النتيجة المطلوبة: النتيجة نفسها؛ لا توجد قائمة بديلة ولا تجاوز لمدير النظام.
5. أعد API مع استجابة صلاحيات ناجحة ثم أعد فتح FrmMain.
6. النتيجة المطلوبة: تبنى الشجرة من الشاشات المصرح بها فقط.

## ميزان المراجعة

- أنشئ قيوداً مرحلة داخل فرع وسنة الجلسة، ثم اطلب `GET /api/accounting-reports/trial-balance`.
- يجب أن تتساوى إجماليات المدين والدائن، وألا تظهر قيود فرع أو سنة أخرى.
- اختبر `currencyId` و`costCenterId`: لا تظهر إلا السطور المطابقة.

## الأستاذ العام

- اطلب `GET /api/accounting-reports/general-ledger?accountId=...` ضمن تاريخين.
- تحقق من: الرصيد الافتتاحي قبل أول يوم، حركة المدين/الدائن داخل المدة، والرصد الختامي المتراكم.
- أرسل `accountId` تابعاً لشركة أخرى أو استخدم رمز وصول بلا `GeneralLedger/View`.
- النتيجة المطلوبة: 404 للحساب خارج الشركة و403 لغياب الصلاحية.

## الطباعة والتصدير

- لا توجد عملية طباعة أو تصدير في FrmFinancialReports قبل إضافة API تفويضية منفصلة.
- يجب إضافة الأزرار فقط بعد فرض `ScreenOperation.Print` و`ScreenOperation.Export` من الخادم؛ لا يكفي إخفاؤها من الواجهة.
