# اختبار قبول — فتح سند الصرف المرتبط بطلب الصرف

## الحالة MPR-PV-01 — إنشاء سند وفتحه من الطلب

1. افتح طلب صرف حالته **معتمد** ولا يملك سند صرف مرتبطاً.
2. اختر **إنشاء سند صرف** ثم اختر صندوقاً أو بنكاً نشطاً ومربوطاً بالحسابات.
3. أكد الإنشاء وتحقق من ظهور رقم السند الأخضر داخل تفاصيل الطلب.
4. اضغط على رقم السند.

النتيجة المقبولة: تنتقل الشاشة إلى تفاصيل سند الصرف نفسه، ولا يظهر زر إنشاء سند آخر للطلب.

## الحالة MPR-PV-02 — منع الإنشاء المكرر

1. ارجع إلى تفاصيل طلب الصرف بعد إنشاء السند.

النتيجة المقبولة: رقم السند يبقى رابطاً قابلاً للفتح، وزر **إنشاء سند صرف** مخفي. يبقى منع إنشاء سند ثانٍ محكوماً أيضاً من API.
