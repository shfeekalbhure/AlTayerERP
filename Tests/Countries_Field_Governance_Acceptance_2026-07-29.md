# اختبار قبول وحوكمة حقول شاشة الدول

**الفرع:** `agent/unified-phase1-screens`  
**التاريخ:** 2026-07-29  
**قيد الدمج:** لا دمج إلى `master` دون موافقة مالك المشروع.

## 1. الحقول المعتمدة

### إلزامية

- كود الدولة.
- اسم الدولة بالعربية.

### اختيارية ومفيدة

- اسم الدولة بالإنجليزية.
- ISO Alpha-2.
- ISO Alpha-3.
- مفتاح الاتصال الدولي.
- رمز العملة الرسمية ISO.
- اسم الجنسية بالعربية.
- ترتيب الظهور.
- الملاحظات.

### للقراءة فقط

- الحالة.
- أنشئ بواسطة.
- تاريخ الإنشاء.
- عدل بواسطة.
- تاريخ التعديل.
- عدد التعديلات.
- عدد مرات الطباعة.

## 2. قرار الحقول

- لا يضاف عمود جديد في هذه الحزمة.
- لا يحذف أي عمود من جدول `countries`.
- لا يضاف اسم الجنسية بالإنجليزية قبل التحقق من وجود مستهلك فعلي له في الأطراف والتقارير.
- يبقى رمز العملة الرسمية في الدولة كرمز ISO مرجعي، ولا يستخدم كسعر صرف أو كبديل عن جدول العملات.
- زر «إعادة» مكرر وظيفيًا مع زر «جديد» ويجب إزالته من شريط الإجراءات عند تعديل الملف الكامل بأمان.

## 3. اختبارات القبول المحلية

### فتح الشاشة

1. افتح: التهيئة والإعدادات ← المراجع الجغرافية ← الدول.
2. تحقق من ظهور الشعار والعنوان واتجاه RTL.
3. تحقق من ظهور بطاقة البيانات والبحث والجدول وتذييل التدقيق دون قص.

**النتيجة المتوقعة:** الشاشة متجاوبة ولا تظهر عناصر التخطيط القديم.

### تحميل البيانات

1. شغّل API.
2. افتح الشاشة.
3. تحقق من ظهور الدول النشطة والموقوفة في الجدول.
4. تحقق من عدد السجلات.

**دليل القبول:** صورة للشاشة والجدول ورسالة عدم وجود أخطاء اتصال.

### إنشاء دولة

1. اضغط «جديد».
2. أدخل كودًا فريدًا واسمًا عربيًا.
3. أدخل ISO2 بحرفين وISO3 بثلاثة أحرف.
4. أدخل رمز عملة من ثلاثة أحرف.
5. احفظ.

**النتيجة المتوقعة:** إنشاء الدولة بحالة نشطة، وتسجيل عملية INSERT في التدقيق.

### منع البيانات غير الصحيحة

- ISO2 بطول غير حرفين: يرفض.
- ISO3 بطول غير ثلاثة أحرف: يرفض.
- رمز عملة بطول غير ثلاثة أحرف: يرفض.
- كود دولة مكرر: يرفض.
- كود أو اسم عربي فارغ: يرفض.

### التعديل

1. اختر دولة من الجدول.
2. تحقق من عودة جميع الحقول.
3. عدّل الاسم أو الملاحظات.
4. احفظ.

**النتيجة المتوقعة:** تحديث السجل، زيادة عداد التعديل، وعرض المستخدم والتاريخ.

### البحث والتصفية

- ابحث بالكود.
- ابحث بالاسم العربي.
- ابحث بالاسم الإنجليزي.
- صفِّ حسب نشط وموقوف.

**النتيجة المتوقعة:** تظهر الصفوف المطابقة فقط ويظل عدد السجلات الكلي موثقًا.

### الإيقاف وإعادة التفعيل

1. اختر دولة نشطة.
2. اضغط «إيقاف» وأدخل سببًا.
3. تحقق من منع الإيقاف دون سبب.
4. أعد التفعيل بسبب إلزامي.

**النتيجة المتوقعة:** لا حذف فعلي، وتتغير الحالة مع تسجيل السبب والمستخدم والتاريخ.

### الطباعة

1. اختر دولة.
2. افتح المعاينة.
3. تحقق من تسجيل PRINT وازدياد عداد الطباعة.

**البيانات المطلوبة في المطبوعة:** الكود، الاسمان، ISO2، ISO3، مفتاح الاتصال، رمز العملة، الجنسية، والحالة.

## 4. تعديلات برمجية معلقة حتى توفر الملف الكامل

- منع تكرار ISO2 وISO3 على مستوى API.
- التحقق من صيغة مفتاح الاتصال الدولي.
- إزالة زر «إعادة» المكرر.
- استكمال بيانات المطبوعة.

لا تعتبر شاشة الدول مغلقة نهائيًا قبل نجاح Build API وDesktop وAndroid وتنفيذ الاختبارات أعلاه محليًا.
