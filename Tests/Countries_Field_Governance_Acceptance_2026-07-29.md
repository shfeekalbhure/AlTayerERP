# اختبار قبول وحوكمة حقول شاشة الدول

**الفرع:** `agent/unified-phase1-screens`  
**التاريخ:** 2026-07-29  
**قيد الدمج:** لا دمج إلى `master` دون موافقة مالك المشروع.

## 1. الحقول المعتمدة

### إلزامية

- كود الدولة.
- اسم الدولة بالعربية.

### اختيارية ومفيدة

- اسم الدولة بالإنجليزية.
- ISO Alpha-2.
- ISO Alpha-3.
- مفتاح الاتصال الدولي.
- رمز العملة الرسمية ISO.
- اسم الجنسية بالعربية.
- ترتيب الظهور.
- الملاحظات.

### للقراءة فقط

- الحالة.
- أنشئ بواسطة.
- تاريخ الإنشاء.
- عدل بواسطة.
- تاريخ التعديل.
- عدد التعديلات.
- عدد مرات الطباعة.

## 2. قرار الحقول

- لا يضاف أو يحذف أي عمود في هذه الحزمة.
- لا يضاف `Unique Index` في قاعدة البيانات ضمن هذا التنفيذ.
- منع تكرار `ISO2` و`ISO3` ينفذ خادميًا مع تجاهل السجل الحالي أثناء التعديل.
- يبقى رمز العملة الرسمية مرجع ISO ولا يستخدم كسعر صرف أو كبديل عن جدول العملات.
- زر «إعادة» مكرر وظيفيًا مع زر «جديد» وقد أزيل من شاشة الدول فقط.
- زر «جديد» هو المسار الوحيد لتصفير الحقول والعودة إلى وضع الإضافة.

## 3. مصفوفة اختبارات القبول

| رقم | الاختبار | خطوات الإدخال | النتيجة المتوقعة |
|---|---|---|---|
| CTRY-01 | قبول ISO صحيح | أدخل `ye` و`yem` ثم احفظ | يحول الخادم القيم إلى `YE` و`YEM` ويقبل الحفظ |
| CTRY-02 | إزالة المسافات | أدخل ` y e ` و` y e m ` | تزال المسافات وتصبح `YE` و`YEM` |
| CTRY-03 | رفض ISO2 بطول خاطئ | أدخل `Y` أو `YEM` | رسالة: رمز ISO2 يجب أن يتكون من حرفين إنجليزيين فقط |
| CTRY-04 | رفض ISO3 بطول خاطئ | أدخل `YE` أو `YEMN` | رسالة: رمز ISO3 يجب أن يتكون من ثلاثة أحرف إنجليزية فقط |
| CTRY-05 | رفض حروف غير إنجليزية | أدخل `يـ` أو `Y2` | رفض واضح من الخادم |
| CTRY-06 | رفض ISO2 مكرر | احفظ دولة ثانية بقيمة ISO2 مستخدمة | `409 Conflict` ورسالة: رمز ISO2 مستخدم مسبقاً لدولة أخرى |
| CTRY-07 | رفض ISO3 مكرر | احفظ دولة ثانية بقيمة ISO3 مستخدمة | `409 Conflict` ورسالة: رمز ISO3 مستخدم مسبقاً لدولة أخرى |
| CTRY-08 | تعديل السجل نفسه | افتح الدولة وعدل الاسم مع إبقاء ISO كما هو | ينجح؛ شرط التكرار يستبعد `Country_ID` الحالي |
| CTRY-09 | قبول مفتاح صحيح | أدخل `+967` | يقبل الحفظ |
| CTRY-10 | رفض مفتاح بلا + | أدخل `967` | رسالة عربية واضحة عن صيغة مفتاح الاتصال |
| CTRY-11 | رفض مسافات أو رموز | أدخل `+ 967` أو `+967-1` | يرفض الحفظ |
| CTRY-12 | زر جديد | اختر سجلًا ثم اضغط «جديد» | تصفير الحقول، `Country_ID=0`، الحالة نشطة، والعودة لوضع الإضافة |
| CTRY-13 | النقر على الجدول | اختر صفًا | تعود كل الحقول والحالة وبيانات التدقيق |
| CTRY-14 | البحث والتصفية | ابحث بالكود/الاسم وصفِّ الحالة | تظهر السجلات المطابقة فقط |
| CTRY-15 | الإيقاف | اختر دولة نشطة وأدخل سببًا | تتوقف دون حذف، ويسجل المستخدم والوقت والسبب |
| CTRY-16 | منع الإيقاف بلا سبب | اترك السبب فارغًا | يرفض التنفيذ |
| CTRY-17 | إعادة التفعيل | اختر دولة موقوفة وأدخل سببًا | تعود نشطة ويسجل التدقيق |
| CTRY-18 | الطباعة | اختر دولة واضغط طباعة | تسجل `PRINT` وتزداد `Print_Count` وتظهر المعاينة الكاملة |
| CTRY-19 | عدم تأثر المحافظات | افتح المحافظات وحمّل/احفظ/عدّل سجل اختبار | جميع الوظائف تعمل كما قبل |
| CTRY-20 | عدم تأثر المدن | افتح المدن وحمّل/احفظ/عدّل سجل اختبار | جميع الوظائف تعمل كما قبل |

## 4. بيانات المطبوعة المعتمدة

- كود الدولة.
- الاسم العربي والإنجليزي.
- ISO2 وISO3.
- مفتاح الاتصال.
- رمز العملة.
- الجنسية.
- الحالة.
- الملاحظات.
- أنشئ بواسطة وتاريخ الإنشاء.
- عدل بواسطة وتاريخ التعديل.
- عدد التعديلات.
- عدد مرات الطباعة بعد تسجيل العملية الحالية.

## 5. اختبار عدم التأثر

1. افتح شاشة المحافظات وتأكد من تحميل الدول النشطة.
2. نفذ النقر والحفظ والتعديل والبحث والإيقاف وإعادة التفعيل.
3. افتح شاشة المدن وتأكد من التسلسل الدولة ← المحافظة.
4. نفذ النقر والحفظ والتعديل والبحث والإيقاف وإعادة التفعيل.
5. افتح شاشة الفروع وتأكد من تحميل الدولة والمحافظة والمدينة.
6. افتح شاشة الشركات للتأكد من عدم عودة خطأ `CS0111`.

## 6. دليل القبول المطلوب

- صورة شاشة الدول بعد إزالة زر «إعادة».
- صورة رسالة رفض ISO2 المكرر.
- صورة رسالة رفض ISO3 المكرر.
- صورة رسالة مفتاح الاتصال غير الصحيح.
- صورة المعاينة المطبوعة والعداد بعد الزيادة.
- سجل نجاح Build API وDesktop وMobile Android.
- نتيجة تشغيل المحافظات والمدن دون أخطاء.

لا تعتبر شاشة الدول مغلقة نهائيًا قبل نجاح جميع Builds وتنفيذ الحالات أعلاه محليًا على قاعدة اختبار.
