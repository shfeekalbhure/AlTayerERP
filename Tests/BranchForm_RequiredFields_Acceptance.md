# اختبار قبول شاشة الفروع — حقول إلزامية وموقع هرمي

## قبل البدء

- شغّل API وسجّل الدخول بحساب يملك عرض المراجع الجغرافية وتعديل الفروع.
- افتح شاشة **الفروع** فقط. لا تنتقل إلى شاشة أخرى قبل تسجيل النتيجة.

## التحقق البصري

1. تظهر العبارة عند تمرير المؤشر على الحقول الإلزامية: «الحقول ذات الخلفية الصفراء مطلوبة».
2. تكون الحقول الإلزامية ذات لون أصفر فاتح جدًا `Color.FromArgb(255, 252, 220)`.
3. تبقى الحقول الاختيارية بيضاء.
4. تظهر الحقول المعطلة أو للقراءة فقط بالرمادي الفاتح، مع نص داكن واضح.
5. لا تتغير ألوان أزرار الاختيار أو حقول التدقيق أو الحقول المحسوبة إلى الأصفر.

## التحقق من الإدخال

1. اضغط **حفظ** دون اختيار الشركة أو الاسم العربي أو نوع الفرع أو الدولة أو المحافظة أو المدينة.
2. لكل حقل ناقص: يظهر إطار أحمر ورسالة عربية قصيرة بجانب الحقل.
3. أدخل القيمة الصحيحة: يختفي الإطار الأحمر وتبقى الخلفية الصفراء الفاتحة.
4. تأكد من عدم ظهور رسائل منبثقة مكررة عند تغيير الشركة أو إعادة تحميل القوائم.

## الموقع الهرمي

1. اختر دولة؛ يجب تحميل محافظاتها النشطة فقط.
2. اختر محافظة؛ يجب تحميل مدنها النشطة فقط.
3. غيّر الدولة؛ يجب مسح المحافظة والمدينة السابقتين.
4. اختر صف فرع محفوظ من الجدول؛ يجب تعبئة الدولة والمحافظة والمدينة المطابقة له.
5. احفظ فرعًا جديدًا وعدّل فرعًا قائمًا ثم أعد فتحه من الجدول؛ يجب بقاء الموقع صحيحًا.

## الوظائف القائمة

- اختبار البحث بالكود والاسم العربي والإنجليزي.
- اختبار الإيقاف وإعادة التفعيل مع السبب المطلوب.
- التحقق من عدم اختيار الفرع نفسه كفرع أب.
- عند تعذر تحميل أي قائمة، تظهر رسالة مستقلة باسم القائمة مرة واحدة فقط.

## دليل القبول

لقطة شاشة للشاشة عند فتحها، ولقطة لحالة خطأ تحقق، ولقطة بعد اختيار دولة/محافظة/مدينة، مع نتيجة حفظ وتعديل ناجحين.
