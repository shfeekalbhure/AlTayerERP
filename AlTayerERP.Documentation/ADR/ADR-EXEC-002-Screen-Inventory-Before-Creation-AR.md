# ADR-EXEC-002 — جرد الشاشات قبل الإنشاء وربطها بشجرة النظام

## الحالة
معتمد وملزم.

## المشكلة
إنشاء شاشة موجودة مسبقاً أو إنشاء شاشة جديدة دون تعريفها في كتالوج النظام وشجرة الصلاحيات يؤدي إلى ازدواجية في الكود، واختلاف في التسمية، وتعطل الصلاحيات والتنقل، وصعوبة الصيانة لاحقاً.

## القرار
قبل إنشاء أي شاشة جديدة في المرحلة الأولى يجب تنفيذ جرد رسمي للشاشات وتقسيمها إلى الحالات التالية:

1. **موجودة ومكتملة**: لا يعاد إنشاؤها ولا يعاد تصميمها إلا عند وجود خلل يمنع التشغيل.
2. **موجودة وتحتاج استكمالاً**: تستكمل داخل نفس الكلاس ونفس المسار دون إنشاء شاشة بديلة أو مكررة.
3. **غير موجودة ومطلوبة**: تنشأ وفق القالب العربي الموحد، ثم تسجل في كتالوج الشاشات، وتربط بشجرة النظام والصلاحيات.
4. **مقترحة لمرحلة لاحقة**: توثق فقط ولا تنفذ ضمن المرحلة الأولى.

## شروط إنشاء أي شاشة

لا يسمح بإنشاء شاشة جديدة قبل تحديد العناصر التالية:

- `Screen_Code` فريد وثابت.
- الاسم العربي للشاشة.
- اسم الكلاس والمسار داخل المشروع.
- الوحدة الرئيسية والفرعية في شجرة النظام.
- نوع الشاشة: إعداد، تشغيل، بحث، مراجعة، تقرير، أو إدارة.
- الصلاحيات المطلوبة: عرض، إضافة، تعديل، حذف، اعتماد، ترحيل، طباعة، وتصدير.
- الجداول والحقول المرتبطة.
- واجهات API المطلوبة.
- الاختصارات ورسائل التحقق.
- سيناريوهات الاختبار والقبول.

## الربط الإلزامي بشجرة النظام

كل شاشة جديدة يجب أن:

1. تسجل في جدول `System_Screens` أو الكتالوج المعتمد للشاشات.
2. تحمل كوداً ثابتاً غير مرتبط باسم الكلاس فقط.
3. توضع تحت الوحدة الصحيحة في شجرة النظام.
4. لا تظهر للمستخدم إلا إذا امتلك صلاحية العرض.
5. تطبق صلاحيات العمليات داخل الشاشة، وليس صلاحية العرض فقط.
6. تستخدم نفس `Screen_Code` في سطح المكتب وواجهة الهاتف وطلبات API والسجلات الرقابية.

## ترتيب التنفيذ

يكون التنفيذ على دفعات مترابطة وفق الأولوية التالية:

1. النظام والأمن والتدقيق.
2. المستخدمون والصلاحيات.
3. التهيئة والعدادات والمزامنة.
4. الاعتمادات والرقابة.
5. العمليات المالية.
6. البحث الموحد.
7. التقارير.
8. النسخ الاحتياطي والإدارة.

## معيار الإكمال

لا تعتبر الشاشة مكتملة لمجرد ظهورها في شجرة النظام. يجب أن تكون واجهتها عربية RTL، ومربوطة بخدمة فعلية أو موسومة بوضوح بأنها غير مفعلة، وتطبق الصلاحيات، وتسجل العمليات الحساسة، وتجتاز اختبارات القبول المعتمدة.
