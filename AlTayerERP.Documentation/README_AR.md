# مركز توثيق مشروع AlTayerERP

هذا المجلد هو المرجع الرسمي لجميع وثائق مشروع **الطائر AlTayerERP**، ويخضع لنفس إدارة الإصدارات والمراجعات المعتمدة للكود.

## قواعد التوثيق المعتمدة

1. أسماء المشاريع والمجلدات والكلاسات والخصائص والدوال تكتب باللغة الإنجليزية.
2. التعليقات داخل الكود وتوثيق XML تكتب باللغة العربية.
3. كل قرار معماري يسجل في ملف مستقل برقم ADR.
4. كل وحدة وظيفية رئيسية يجب أن تحتوي على دليل عربي يوضح الهدف، الحدود، قواعد العمل، قاعدة البيانات، واجهات API، الشاشات، الصلاحيات، والاختبارات.
5. الكراسة التنفيذية الرئيسية وثيقة تراكمية واحدة، ولا تنشأ كراسة بديلة عند كل تعديل.
6. كل تعديل جوهري يضاف إلى سجل التغييرات ويرفع رقم إصدار الكراسة.

## بنية التوثيق

- `Engineering-Constitution-AR.md`: الدستور الهندسي والقرارات الحاكمة.
- `Phase1-Implementation-Book-AR.md`: الكراسة التنفيذية الرئيسية للمرحلة الأولى.
- `ADR/`: قرارات التصميم والمعمارية.
- `Developer-Guide-AR.md`: دليل المطور.
- `Database-Guide-AR.md`: دليل قاعدة البيانات.
- `API-Guide-AR.md`: دليل واجهات API.
- `Release-Notes-AR.md`: سجل الإصدارات.
- `SECURITY-AND-SETUP-AR.md`: دليل إعداد الاتصال والأمان والتشغيل.
- `READINESS-REVIEW-2026-08-19-AR.md`: تقرير مراجعة وتجهيز خط الأساس الحالي.
- `../Database/README_AR.md`: ترتيب تشغيل SQL وEF Core والتحقق بعد الترحيل.
- `OPEN-PR-TRIAGE-AR.md`: فرز طلبات الدمج المفتوحة وقرارات المراجعة.

## المرجعية

عند التعارض بين وثائق المشروع تكون الأولوية بالترتيب التالي:

1. القرارات المعمارية المعتمدة ADR.
2. الدستور الهندسي.
3. الكراسة التنفيذية الرئيسية.
4. أدلة الوحدات والشاشات.
5. الملاحظات المؤقتة ومحاضر النقاش.
