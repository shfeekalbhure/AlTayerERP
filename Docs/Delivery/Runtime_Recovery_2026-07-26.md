# معالجة أخطاء التشغيل 404 و500 — AlTayerERP

## الأعراض التي عولجت

- شاشة الفروع: تعذر تحميل أنواع الفروع والعملات مع `404`.
- شاشة المجموعات التجارية والشركات: تعذر التحميل مع `500`.

## السبب

1. خدمة API المشغلة أقدم من نسخة المشروع ولا تحتوي مسار `api/branch-reference-lookups`.
2. قاعدة `altayer_erp_db` لم تستكمل أعمدة توسعة وتدقيق المجموعات والشركات.
3. جدول `branch_types` غير موجود أو غير مهيأ في القاعدة الحالية.

## ترتيب الترقية على نسخة اختبار من `altayer_erp_db`

نفّذ الملفات التالية بالترتيب، مرة واحدة. كلها ترقيات آمنة لا تحذف بيانات:

1. `Database/2026-07-23_expand_tenant_groups.sql`
2. `Database/2026-07-24_add_tenant_group_audit.sql`
3. `Database/2026-07-24_add_company_audit.sql`
4. `Database/2026-07-24_add_record_status_audit.sql`
5. `Database/2026-07-26_branch_types_compatibility.sql`

بعدها أعد تشغيل مشروع `AlTayerERP.API`، ثم شغّل النسخة المحدثة من `AlTayerERP.Desktop` وسجل الدخول من جديد.

## نتيجة متوقعة

- تحميل الشركات والمجموعات دون `500`.
- تحميل أنواع الفروع والعملات من API بدلاً من قيم ثابتة.
- منع حفظ فرع عندما لا توجد عملة نشطة للشركة أو لم يحدد المستخدم نوع الفرع.
